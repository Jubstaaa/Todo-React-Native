# Todo React Native

A small to-do app built with React Native and Expo. Tasks are added through a modal, marked done by swiping, and moved to a separate completed list. State lives in memory only.

## Stack

- React Native 0.70 with Expo SDK 47
- react-native-swipe-gestures
- react-native-toast-message
- react-native-vector-icons

## Running it

```sh
npm install
npm start          # expo start
npm run android
npm run ios
npm run web
```
